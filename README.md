# Patrick Foster's Personal website

Built with Create React App and React Router.

### Check it out at [patrickrfoster.com](https://www.patrickrfoster.com)

Run locally with `npm start`.

## Available scripts

- `npm start` — run the app locally at http://localhost:3000
- `npm run build` — produce an optimized production build in `build/`
- `npm test` — run the test runner in watch mode

## Project layout

- `src/components` — page and UI components, each with a co-located stylesheet
- `src/constants` — static content (articles, reading list, talks, projects)
- `public` — static assets and the HTML shell
